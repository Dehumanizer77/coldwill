⬇ Stiahnuť key-file

hex: {{.KeyHex}}

Pozor: toto je 1. krok z 3. Samotný key-file ešte nie je prístup k Bitcoinu — treba ešte databázu .kdbx a passphrase z obálky.

①  časti
       │   (nástroj ich poskladá dokopy)
       ▼
   key-file (16 bajtov / hex)        ← TOTO práve vzniklo
       │   + databáza .kdbx (KeePass)
       ▼
②  SEED + ďalšie informácie a prístupy
       │   + passphrase (z obálky)
       ▼
③  obnova peňaženky  →  Bitcoin ₿

Ďalej

  1. Otvor svoju .kdbx v KeePassXC; ako ochranu zvoľ Key file = tento súbor (do poľa Heslo nič nezadávaj).
  2. Dostaneš sa k seedu a ďalším informáciám a prístupom; passphrase k peňaženke vezmi z obálky (banka / e-mail).
  3. Na hardvérovej peňaženke obnov zo seedu + passphrase.
